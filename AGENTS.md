# EES-AMS

Cross-platform Tauri v2 desktop app for elementary school attendance management.

**Read the consolidated knowledge base → [`docs/AGENTS.md`](docs/AGENTS.md)**

Key locations: frontend in `src/`, TypeScript backend in `src/lib/`, UI components in `src/lib/components/`, SF2 automation in `src/lib/features/sf2/` with the ExcelJS workbook layer in `src/lib/features/excel/`; `src-tauri/` is Tauri plugin registration only.
